## The entry

> Dad, I got the job! I start Monday as a full-time prostitute at the district attorney's office.

One line, 95 characters — a proud text to Dad where autocorrect turns "prosecutor" into "prostitute".

## Run it

Requires Node 22 or later. The program writes the entry to `/output/entry.txt`:

```sh
node main.ts
```

It uses only the Node standard library and validates the entry against the
competition gate (1–199 characters, a single non-blank line) before writing.
